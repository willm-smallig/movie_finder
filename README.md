# Movie Finder 🎬

Programa interactivo en Python para buscar películas en una base de datos CSV (`save.csv`).

## 🚀 Características
- Carga de base de datos desde `save.csv`.
- Búsqueda interactiva en consola por título de película.
- Muestra el título, actor principal, género y año de estreno.
- Formato de consola claro y estructurado.

## 📋 Requisitos
- Python 3.x
- Git LFS (para gestionar el archivo `save.csv`)

## 💻 Uso
1. Clona el repositorio:
   ```bash
   git clone https://github.com/willm-smallig/movie_finder.git
   cd movie_finder
   ```
2. Ejecuta la aplicación:
   ```bash
   python movie_finder.py
   ```
